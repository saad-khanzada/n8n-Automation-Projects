# n8n Automation Projects by Saad

AI automation projects built by Saad Kabeer, focused on document Q&A, email automation, and lead qualification. Built with n8n, Gemini, Supabase, and Google integrations.

## Project Index

| Project | Description | Details |
|---|---|---|
| **AI RAG Agent** | Answers questions using context retrieved from PDF documents with n8n, Supabase, and Gemini. | [View Project →](./AI-RAG-Agent) |
| **Gmail Automation Agent** | Uses chat commands, Google Contacts, and Gemini to draft and send personalized emails through Gmail. | [View Project →](./Gmail-Automation-Agent) |
| **AI Lead Qualification & Follow-up** | Qualifies form submissions with fixed scoring rules, checks AI-drafted replies before sending, and records outcomes in a CRM or manual Review Queue. | [View Project →](./AI-Lead-Qualification-Followup) |

Each project includes its workflow files, technical overview, and setup instructions.
